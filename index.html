Proxmox-390

Proxmox VE 9 for IBM Z and LinuxONE.

Proxmox-390 is a port of Proxmox VE 9 (Debian 13 "trixie") to s390x. The whole stack is built natively: web interface, API, QEMU/KVM, LXC, ZFS, clustering and backup. QEMU and the VM manager have been extended to support mainframe devices, so you can run more than just Linux guests.

The project is under development. There is no public release yet.

Features

Proxmox VE

  • Web interface and REST API
  • KVM virtual machines (virtio disk and network)
  • LXC containers, s390x template
  • ZFS and LVM-thin storage
  • Live migration, also with local disks
  • Snapshots, backup and restore
  • OVA import and export
  • Clustering

Mainframe

  • qeth network devices
  • CKD DASD (3390, 3380)
  • FBA DASD
  • 3270 terminals, models 2 to 5
  • SCLP line-mode, 3270 and ASCII consoles
  • Console hardcopy log, syslog forwarding
  • IPL from DASD, tape or network, with loadparm
  • Device numbers and CU/device types per device

System requirements

HardwareIBM z14
Memory16 GB minimum
System diskFBA DASD (FCP SCSI LUNs: coming soon)
NetworkOSA (qeth)

Only verified configurations are listed. Other machines and setups may work, but haven't been tested.

Installer

The installer runs on the SCLP line-mode console and can do interactive and unattended (answer file) installs. It is IPLed from a kernel, initrd and parmfile; there is no ISO.

Downloads and installation documentation will be published here.
