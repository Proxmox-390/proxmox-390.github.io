Proxmox-390

Proxmox Virtual Environment 9 on IBM Z and LinuxONE: the full Proxmox VE stack, built natively for s390x, with first-class support for mainframe I/O.

Under active development. No public release yet.

What it is

Proxmox-390 brings the Proxmox VE 9 virtualization platform (Debian 13 "trixie") to the s390x architecture. Every package of the stack is built natively for s390x: the web interface and API, the KVM/QEMU virtual machine manager, LXC containers, ZFS, clustering and backup.

On top of that, the port teaches Proxmox VE about the devices and conventions of the mainframe, so that guests which expect real mainframe hardware can be created, run and managed from the familiar Proxmox web interface.

Mainframe features

qeth networking

OSA-style qeth network devices for guests, bridged onto Proxmox Linux bridges. qeth devices on the host can be brought online from the node's network panel.

CKD DASD

Count-key-data disks (3390 and 3380 models) with configurable device numbers and device/control-unit types. Volumes can be imported from existing images, live-migrated and snapshotted.

FBA DASD

Fixed-block DASD for guests, and FBA volumes as the system disk of the Proxmox host itself.

3270 terminals

Local 3270 display terminals at the device numbers you choose, shown in the web console with the right model size (model 2 to 5). Sessions stay connected for the lifetime of the VM.

SCLP consoles

The SCLP line-mode console with a persistent, rotated hardcopy log (optionally forwarded to syslog), the SCLP 3270 integrated console, and the SCLP ASCII console for Linux guests.

IPL control

IPL from DASD, tape or network with a load parameter, using a dedicated mainframe machine type.

The rest of Proxmox VE

  • Linux guests with virtio disks and network
  • LXC containers with an s390x container template
  • ZFS and LVM-thin storage
  • Live migration, including local DASD
  • Snapshots, backups and OVA import/export
  • Clustering and the full REST API

Installer

Proxmox-390 comes with its own installer, which runs on the SCLP line-mode console and supports both interactive and unattended (answer file) installs. It is IPLed from a small set of files (kernel, initrd and parameter file), not from an ISO.
