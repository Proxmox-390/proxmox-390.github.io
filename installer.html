Proxmox-390

Installer 9.2 beta 1

Beta. This installer has been tested as a KVM guest on an IBM z14 (virtio, qeth, emulated FBA and ECKD DASD). Installing directly into an LPAR from the HMC/SE and from the z/VM reader has not been validated yet. Please report how it goes.

What you need

  • IBM z14 or later, an LPAR (or z/VM or KVM guest) with at least 16 GB of memory
  • A system disk: FBA DASD (FCP SCSI LUNs: coming soon), 32 GB or more
  • An OSA (qeth) network device with access to the internet, directly or through an HTTP proxy

The installer downloads everything during the installation (Debian from deb.debian.org, Proxmox-390 from its own repository); it does not contain the packages.

Contents of the tarball

kernel.imgLinux kernel
initrd.imgInitial RAM disk with the installer

Starting the installer

HMC/SE

Unpack the tarball on an FTP server (or removable media) reachable by the SE. Use Load from Removable Media or Server, point it at the directory and select proxinst.ins. Add your parameters to parmfile first (see below). Open the Operating System Messages console: the installer runs on it.

z/VM

Transfer kernel.img as KERNEL IMG and initrd.img as INITRD IMG (binary, fixed 80), parmfile as PARMFILE PRM and proxinst.exec as PROXINST EXEC (text), then run PROXINST. It punches the files to your reader and IPLs from it.

KVM

qemu-system-s390x -machine s390-ccw-virtio -accel kvm -cpu host -m 4096 \
  -kernel kernel.img -initrd initrd.img -append "$(cat parmfile) proxinst.…" …

Parameters

Put these in parmfile (or on the KVM command line). Without them the installer asks.

proxinst.netdev=Network device, e.g. 0.0.0600
proxinst.hostname=, proxinst.domain=Host name and DNS domain
proxinst.ip4=, proxinst.gw4=dhcp, none or 192.0.2.10/24; gateway
proxinst.ip6=, proxinst.gw6=auto, dhcp, none or an address/prefix; gateway
proxinst.dns=DNS servers, comma separated
proxinst.answer=URL of an answer file for an unattended install
proxinst.proxy=HTTP proxy, http://host:port
proxinst.mirror=, proxinst.security=Debian mirror and security mirror
proxinst.proxport=Proxmox-390 repository (default: the public one)
proxinst.ntp=NTP servers
proxinst.tls-trust-fingerprint=sha256:… of a certificate to trust (TLS inspection proxies)
proxinst.shellStart a shell instead of the installer

Example:

proxinst.netdev=0.0.0600 proxinst.hostname=pve1 proxinst.domain=example.com proxinst.ip4=192.0.2.10/24 proxinst.gw4=192.0.2.1 proxinst.ip6=none proxinst.dns=192.0.2.53

Interactive installation

The installer runs on the SCLP line-mode console. It asks, in this order: host name and domain, network interface, IPv4 and IPv6, DNS servers, Debian mirror, security mirror, Proxmox-390 repository and HTTP proxy (defaults are offered; an empty line or . takes the default), then the root password, SSH keys, an administrator e-mail address and the time zone, and finally the disks: system disk, data disks, LVM sizes and an optional ZFS pool. Nothing is written before you type yes at the summary.

Notes: input lines are limited to 251 characters; end a line with \ to continue it. SSH keys can be given as an https URL of an authorized_keys file. If a certificate check fails (for example behind a TLS inspection proxy), the installer shows the certificate and asks whether to trust it.

Unattended installation

Pass proxinst.answer=<url> and provide a TOML answer file. Minimal example:

[global]
fqdn = "pve1.example.com"
mailto = "admin@example.com"
timezone = "Europe/Brussels"
root-password-hashed = "$6$…"
root-ssh-keys = ["https://example.com/admin.keys"]

[network]
source = "from-dhcp"

[disk-setup]
filesystem = "ext4"
system-disk = "0.0.0100"
disk-list = ["0.0.0101", "0.0.0102", "0.0.0103"]
data = "zfs"
zfs.raid = "raidz-1"

Further sections: [install] (mirrors, repository, http-proxy, tls-trust-ca, tls-trust-fingerprint, ntp-servers, extra-packages) and [s390x] (devices to set online, DASD formatting).

After the installation

The system re-IPLs from the installed disk by itself. The installer prints the web interface address: https://<address>:8006/, user root, realm Linux PAM. The log of the installation is in /var/log/proxinst.log. Updates come with the usual apt update && apt full-upgrade.

Known limitations

  • Tested as a KVM guest on a z14; LPAR (HMC/SE) and z/VM installs not yet validated
  • Installation onto FCP SCSI LUNs is not supported yet
  • Network installation only
